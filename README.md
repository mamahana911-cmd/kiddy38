# Kiddy38 Fashion
Katalog fashion mobile-first untuk GitHub Pages.

## Fitur
- Katalog produk
- Pencarian dan kategori
- Detail produk
- Pesan langsung via WhatsApp
- Testimoni pembeli dan reseller
- Notifikasi aktivitas pembelian demo
- Produk dapat diganti melalui localStorage untuk pengembangan berikutnya

## Catatan
Notifikasi pembelian pada versi ini adalah **data contoh/demo**, bukan data order nyata. Untuk notifikasi pembelian nyata dan katalog yang tersinkron untuk semua pengunjung, hubungkan ke database/order backend (mis. Supabase) pada tahap berikutnya.
